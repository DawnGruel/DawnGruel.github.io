# 产品经理知识

## 常用缩写

* [**USP**](./USP) 是 **Unique Selling Proposition** 的缩写，中文通常翻译为 **独特卖点** 或 **独特销售主张**。
* [**KPI**](./KPI) 是 **Key Performance Indicator** 的缩写，中文通常翻译为 **关键绩效指标**。
* [**UGC**](./UGC)是 **User-Generated Content** 的缩写，中文通常翻译为 **用户生成内容**。  
* [**MoSCoW 法则**](./MoSCow) 是一种用于需求优先级划分的方法，广泛应用于项目管理、产品开发和软件需求分析中。它帮助团队根据需求的重要性和紧急程度对任务进行分类，确保资源的合理分配和目标的优先实现。
* [**Wireframe**](./Wireframe) 中文通常翻译为 **线框图**，是用户界面（UI）设计中一种重要的工具，主要用来展示产品页面的结构和布局。
